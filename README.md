# 🤖 Telegram-Бот Секретарь | Автоответчик 24/7

Профессиональный асинхронный Telegram-бот, разработанный студией **Domination Squad** для автоматизации обработки входящих сообщений, удержания клиентов и фильтрации лидов.

## 🚀 Стек технологий
* **Python 3.10+**
* **Aiogram 3.x** (Асинхронный фреймворк)
* **Встроенный FSM** (Finite State Machine / Конечные автоматы)
* **Python-dotenv** (Безопасное хранение конфигурации)

## 🎯 Основной функционал
1. **Интерактивное меню:** Быстрые ответы на популярные вопросы клиентов (цены, условия работы, официальность/чеки).
2. **Умный FSM-фильтр (Вариант Б):** Защита от левого ввода. Если пользователь пишет случайный текст во время выбора вопроса, бот вежливо просит использовать кнопки.
3. **Сбор кастомных брифов:** Перевод пользователя в режим ожидания ТЗ. Бот принимает **любой тип контента** (текст, фото, документы, голосовые сообщения).
4. **Мгновенная копия в ЛС:** Бот делает чистую копию сообщения клиента (`send_copy`) и пересылает её администратору с кликабельной ссылкой на юзернейм заказчика.

## 🛠 Установка и запуск

1. Клонируйте репозиторий.
2. Создайте файл `.env` в корне проекта и заполните его:
   ```env
   BOT_TOKEN=ваш_токен_бота
   ADMIN_ID=ваш_числовой_id
   ```
3. Установите зависимости:
   ```bash
   pip install aiogram python-dotenv
   ```
4. Запустите бота:
   ```bash
   python main.py
   ```
